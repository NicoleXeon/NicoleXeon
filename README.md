Mechatronics engineer, flight systems builder (UAV/FPV, ArduPilot, INAV), and pure Debian/Linux homelab architect. I build hardware, firmware, and software bridging IoT lighting, DSP audio streams, and desktop system utilities.

---

#### 🛠️ What I'm Working On

* **WLED & Audio DSP:** 
  * [`WLED_Audio_Bridge_LMS`](https://github.com/NicoleXeon/WLED_Audio_Bridge_LMS) — Headless digital bridge streaming real-time FFT spectrum bins directly from Lyrion Music Server to WLED via UDP multicast.
  * [`WLED_Billboard`](https://github.com/NicoleXeon/WLED_Billboard) — RESTful daemon and coordinate engine for 2D WLED matrices with dynamic alerts, pixel graphics, and system metrics.
* **GNOME & Linux Desktop Tooling (C++):**
  * [`GNOME_Settings_Vault`](https://github.com/NicoleXeon/GNOME_Settings_Vault) & [`GNOME_Settings_Transfer`](https://github.com/NicoleXeon/GNOME_Settings_Transfer) — Utilities for backing up, migrating, and synchronizing low-level `dconf` schemas across headless and workstation fleets.
  * [`GNOME_Image_Renamer`](https://github.com/NicoleXeon/GNOME_Image_Renamer) — Lightweight batch metadata and image renaming tool.
* **Hardware & Avionics:**
  * Custom 3D parametric enclosures, light-isolation matrix grids, and structural designs ([Thingiverse: 7391918](https://www.thingiverse.com/thing:7391918)).
  * Long-range autonomous fixed-wing and multirotor UAV flight control stacks.
